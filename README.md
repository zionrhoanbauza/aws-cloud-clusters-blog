<h1>AWS Cloud Clusters Blog is a community blog for AWS members.</h1>

Originally made as a developer challenge for the AWS Builders - UST branch, Cloud Clusters was made with the intent to serve the AWS community by sharing findings, asking questions, and posting updates. 

Cloud Clusters is developed by <b>Zion Rhoan Bauza</b>, a 4th-year Computer Science Student from the University of Santo Tomas.

This application is deployed on Vercel.


IMPORTANT: (for local run)
<b>npm install</b>, set DATABASE_URL and JWT_SECRET in a <b>.env.local</b>, then <b>npm run dev</b>
